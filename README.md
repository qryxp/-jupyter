# 个人网络接单数据分析库 `da`

一个**按业务域拆分模块**的个人接单数据分析库。覆盖四类赛道，每个指标都能像 `pandas` 一样直接调用算出结果，也能一键调出**算法配方（源码+公式）**来学习/复制。

- **域A 技能外包**（设计/开发/文案/翻译/咨询）—— 字段最少、最容易起步
- **域B 小微电商 / 带货 / 闲鱼铺货**
- **域C 自媒体 / 内容接单**（公众号、小红书、B站商单）
- **域D 零工平台视角**（平台方 / 个人接单看板）

> 设计原则：**不把指标写死成"通用公式"**。每个域有自己的字段口径和指标，按模块独立扩展。所有"库的清单数据"集中在分类 `.py` 里，加一个指标 = 加一个带 `@metric` 的函数，自动进清单、自动有配方。

> 若新电脑没有 `pyproject.toml` 只有 `requirements.txt`，可用 `pip install -r requirements.txt` 只装依赖、再用做法 A 安装。

## 三、前期数据清洗（重点）

接单数据常来自 Excel / 平台导出 / 手工台账，脏点主要是**日期格式乱**和**空值表示乱**。

```python
import da
原始 = pd.read_csv("data/sample_skills.csv")        # 日期混了 2026/7/3、16/07/2026、2026年7月5日，"无"是伪空值
干净 = da.数据清洗.清洗管道(原始)                    # 一步到位：去空格→日期强制转换→空值映射填充→去重

# 也可以分步调：
干净 = da.数据清洗.强制日期转换(原始)               # 多格式日期逐个试，转不了的变 NaT 不报错
干净 = da.数据清洗.空值映射填充(干净)               # "无"/"NULL"/"NA"/"-"/"" 等统一成 NaN 再按类型填充
```

可定制：

```python
da.数据清洗.强制日期转换(df, 列="下单时间", 格式=["%Y-%m-%d", "%Y/%m/%d"])
da.数据清洗.空值映射填充(df, 映射={"缺": float("nan")}, 数值列默认填充=0, 文本列默认填充="未知")
```

### 按参照列映射填充（进阶：用已有数据反推空值）

`空值映射填充` 只能整列填（0 / 空串 / 标量）。但很多真实场景是**「另一列有数据，能用来推这一列的空值」**——比如商品类型大量缺失，但商品名称几乎都有，且同一商品名称对应同一个商品类型。

```python
# 用「商品名称」已有的类型，去填「商品类型」的空缺
干净 = da.数据清洗.按参照列填充(原始, 目标列="商品类型", 参考列="商品名称")
```

要点（都体现「看数据调整」，不是无脑执行）：
- **方式** 决定冲突时取哪个值：`"组内最常见值"`（默认，该名称下出现最多的类型）或 `"组内首个"`（该名称下第一个非空类型）。
- **歧义主动提示**：若某个商品名称对应了多个不同的商品类型（脏数据矛盾），函数会打印出来让你人工核对，绝不偷偷选一个。
- **参考列本身为空的行**没有参照依据，一律保留空，不瞎猜。
- 手头已有「名称→类型」对照表时，传 `映射={"A": "电子", "B": "食品"}` 强制覆盖，优先级最高。

## 四·五、能力探测：给一份数据，自动算

你不必背每个指标要哪几列。丢一份数据进来，库替你盘清楚「现有列能算出哪些指标、还差哪一列能解锁更多」——这正好对应"把三列、四列变量同时考虑，尽量榨出可得数据"。

```python
import da, pandas as pd
df = pd.read_csv("data/sample_skills.csv")

# 1) 打印：当前数据能算哪些 + 再补 1 列能解锁哪些
da.能力探测(df)
da.能力探测(df, "技能外包")          # 只看某域

# 2) 一次性把所有能算的指标算出来，返回 {指标名: 结果}
res = da.一键计算(df)
res = da.一键计算(df, "小微电商")
import pandas as pd
pd.Series(res).sort_values(ascending=False)   # 标量结果直接排序看

# 3) 只要"可算指标"的列表（不计算，用于判断）
ms = da.可算指标(df)              # 返回 Metric 对象列表
[ (m.name, m.fields) for m in ms ]   # 看名字和依赖字段
```

原理：每个指标用 `@metric(fields=[...])` 登记了依赖字段，`能力探测` 拿你 df 的列集合去逐一比对——
- 字段全有 → ✅ 可直接算
- 只差 1 列 → 🔧 提示你补这列就解锁
- 差很多 → ❌ 暂不展开

## 五、指标清单（多层级：域 → 子类 → 指标 = 公式）

### 域A 技能外包
- **收益指标**
  - 净到手率 = (实收金额 − 平台抽成 − 成本 − 税费 − 返工折损) / 报价金额
  - 客单价 = 实收金额合计 / 接单量
  - 毛利率 = (实收金额 − 成本) / 实收金额
  - 单均净利润 = 实收金额 − 平台抽成 − 成本  **（3 列）**
  - 综合成本率 = (平台抽成 + 成本 + 税费) / 实收金额  **（4 列）**
  - 渠道净收益率 = (实收金额 − 平台抽成 − 成本) / 报价金额  按渠道分组 **（4+1 列）**
- **产能指标**
  - 时薪 = 实收金额合计 / 交付时长合计(h)
  - 时薪净利 = (实收金额 − 平台抽成 − 成本) / 交付时长h  **（4 列）**
- **质量指标**
  - 返工率 = (返工次数>0 的订单数) / 总订单数
- **渠道指标**
  - 单渠道转化率 = 各渠道成交数 / 该渠道咨询量
  - 老客复购率 = 老客订单数 / 总订单数

### 域B 小微电商
- **规模指标**：销售额 = Σ(单价×销量) ｜ GMV ｜ 净销售额 = Σ实付金额 − Σ退款金额 ｜ 订单数 = COUNT(DISTINCT 订单ID) ｜ 客单价ATV = 净销售额/订单数 ｜ 件单价 ｜ 连带率 = Σ销量/订单数 ｜ GMV退款修正
- **风险指标**：退款率 = Σ退款数/Σ销量 ｜ 金额退款率 = Σ退款金额/Σ实付金额
- **盈利指标**：销售毛利率 = (销售额 − 成本×销量 − 平台扣点) / 销售额
  - 销售毛利额 = 销售额 − 成本 − 平台扣点  **（3 列）**
  - 销售净利率 = (销售额 − 成本 − 平台扣点 − 推广费) / 销售额  **（4 列）**
  - 推广净ROI = (销售额 − 成本 − 推广费) / 推广费  **（3 列）**
  - 盈亏平衡销量 = 固定成本 / (单价 − 单位变动成本)  **（3 列）**
- **库存指标**：动销率 = 有销量SKU数 / 总SKU数
  - 库存周转天数 = 期长天数 / (销售成本 / 平均库存)  **（3 列）**
- **转化漏斗**：曝光点击率 = 点击/曝光 ｜ 点击下单率 = 销量/点击 ｜ 整体转化率 = 销量/曝光
- **线下指标**：坪效 = 销售额/门店面积 ｜ 人效 = 销售额/员工人数

### 域C 自媒体
- **互动指标**：互动率 = (点赞+收藏+评论) / 阅读播放  **（4 列）**
- **变现指标**：千次曝光报价CPM = 商单收入/阅读播放×1000 ｜ 粉丝净值 = 商单收入/粉丝数 ｜ 商单承接率 = 合作数/询价
  - 内容投产比 = 商单收入 / (制作成本 + 投放成本)  **（3 列）**
  - 千粉月收益 = 商单收入 / (粉丝数/1000) / 月份数  **（3 列）**
- **增长指标**：掉粉率 = 掉粉数 / (期初粉丝数 + 新增粉丝数)  **（3 列）**

### 域D 零工平台
- **接单指标**：中标率 = 中标数/投标数 ｜ 纠纷率 = 纠纷数/中标数
  - 复购加权中标率 = (中标数 + 复购数×0.5) / 投标数  **（3 列）**
- **质量指标**：综合履约分 = 准时交付率×0.4 + 好评率×0.4 + (1−纠纷率)×0.1 + 复购率×0.1  **（4 列）**
- **时效指标**：首标时效 = 发单→首标(小时) ｜ 定标时效 = 发单→定标(小时) ｜ 等待时长 = 发单→接单(小时)
  - 任务接标时效 = (首标时长h + 定标时长h + 平均交付时长h) 的平均  **（3 列）**

## 七、加一个新指标（扩展只需 3 步）

```python
# da/skills/profit.py
from .._registry import metric
from ..core.utils import 列存在, 聚合, 安全除法

@metric(name="新指标名", domain="技能外包", category="收益指标",
        fields=["依赖字段1", "依赖字段2"],
        formula="新指标 = ...")
def 新指标名(df, by=None):
    列存在(df, "依赖字段1", "依赖字段2")
    def f(d):
        return 安全除法(d["依赖字段1"].sum(), d["依赖字段2"].sum())
    return 聚合(df, by, f)
```

然后在 `da/skills/__init__.py` 里 `from .profit import 新指标名` 加进 `__all__`，重新 `import da` 即可——自动进清单、自动有配方。

> 支持 `可选列=["税费"]` 参数：这些列缺失时自动按 0 算（视为"没发生"），分母类列（实收金额/销售额…）绝不能放进可选列。详见第十节。
> 嫌手写函数麻烦？直接用命令 `da.更新.加指标(...)` 写文件 + 热加载（见第十二节），连粘都不用粘。

## 九、图表生成（Seaborn / Plotly / PyEcharts）

`da.图表` 让图表也像指标一样"一句话调用"。数据会自动按类别聚合，**参数已为你调好**（白底、配色、数值标签），你只管给 `x` / `y`。

```python
import da, pandas as pd
df = pd.read_csv("data/sample_region_sales.csv")

# 你举的例子：各地区的销售额柱状图
da.图表.柱状图(df, x="地区", y="销售额", title="各地区销售额")          # 默认 plotly（交互）
da.图表.柱状图(df, x="地区", y="销售额", engine="seaborn")            # 静态出版风
chart = da.图表.柱状图(df, x="地区", y="销售额", engine="pyecharts")   # HTML 看板风，可 chart.render("a.html")
```

### 极简调用：一个动词出所有图

不想记函数名？只用 `画` + 中文图表类型名即可，`engine`/`预设` 可省略（取全局默认）：

```python
da.图表.画(df, 类型="柱状图", x="地区", y="销售额")                 # 默认 plotly + 清爽白
da.图表.画(df, 类型="堆叠柱状图", x="地区", y="销售额", stack="品类")
da.图表.画(df, 类型="折线图", x="月份", y="销售额", color="地区")
da.图表.画(df, 类型="气泡图", x="销量", y="销售额", size="销售额")
```

先配一次默认，之后连 `engine` / `预设` 都能省：

```python
da.图表.设定(默认引擎="plotly", 默认预设="商务蓝")
da.图表.画(df, 类型="柱状图", x="地区", y="销售额")     # 直接出商务蓝风格
```

### 样式预设（调用时填名字即可）

内置 4 套调好的配色/主题，三引擎都生效：

| 预设 | 风格 | 适用 |
|------|------|------|
| `清爽白`（默认） | 浅底 + 柔和多彩 | 通用、报告 |
| `商务蓝` | 蓝色系 | 商务 PPT、甲方看板 |
| `活力橙` | 橙暖色 | 新媒体、吸睛 |
| `暗夜` | 深色底 | 暗色主题、投屏 |

```python
da.图表.柱状图(df, x="地区", y="销售额", 预设="商务蓝")
da.图表.饼图(df, x="地区", y="销售额", engine="pyecharts", 预设="活力橙")
da.图表.预设清单()        # 看有哪些预设
da.图表.预设示例()        # 直接打印每种预设的调用代码，抄着用
```

支持的所有图表（参数都可调，详见 `da.图表.图表清单()`）：

```python
da.图表.柱状图(df, x, y, engine="plotly", agg="sum", top_n=None)        # 柱
da.图表.堆叠柱状图(df, x, y, stack, engine="plotly")                    # 堆叠柱（stack=堆叠类别列）
da.图表.折线图(df, x, y, color=None, engine="plotly")                   # 折线（color=多条系列）
da.图表.面积图(df, x, y, color=None, engine="plotly")                   # 面积
da.图表.饼图(df, x, y, engine="plotly")                                 # 饼
da.图表.环形图(df, x, y, engine="plotly")                               # 环形
da.图表.散点图(df, x, y, color=None, engine="plotly")                   # 散点
da.图表.气泡图(df, x, y, size, color=None, engine="plotly")             # 气泡（size=大小列）
da.图表.热力图(df, x, y, z, engine="plotly")                            # 热力（x行 y列 z值）
da.图表.箱线图(df, x, y, engine="plotly")                               # 箱线
da.图表.直方图(df, x, bins=20, engine="plotly")                         # 直方（仅 plotly/seaborn）
```

- `engine`：`"plotly"`（默认，交互）/ `"seaborn"`（静态）/ `"pyecharts"`（HTML 看板）。
- `agg`：**同类怎么汇总**，决定你给的明细行如何合并：
  - `"sum"`（默认）—— 同类求和，最常用（各地区销售额、各渠道成交量）
  - `"mean"` —— 同类求平均（客单价、评分）
  - `"count"` —— 同类计数（订单笔数）
  - `None` —— 数据已是一类一行，原样取两列、不聚合
- `top_n`：柱/条形图只保留 **y 最大的前 N 类**，应对「类别太多/长尾」（如 200 个客户只画前 10）。
- `预设`：**样式主题**——这也是"换黑底"的开关：
  - `清爽白`（默认，白底）｜ `商务蓝` ｜ `活力橙` ｜ `暗夜`（**深色底，投屏/暗色主题用**）
  - 换黑底直接：`da.图表.柱状图(df, x="地区", y="销售额", 预设="暗夜")`
  - 内部原理（你一般不用管）：plotly 把 template 从 `plotly_white` 切成 `plotly_dark`、seaborn 把 style 从 `whitegrid` 切成 `darkgrid`、pyecharts 把配色换成亮色系。
- 每个图表函数都带**详细参数 docstring**（含上面这些），在 Jupyter 里 `da.图表.柱状图??` 或 `da.图表.查看配方(da.图表.柱状图)` 可看。

看"优调好的源码"（学习或改参数）：


## 十、指标缺列容错（数据少几列也能算）

接单数据常常"记了这笔、漏了那笔"。有些**附加成本/费用类**字段（如 税费、平台抽成、成本）可能没记；
这类列在指标里被标记为「**可选列**」，数据里缺了会自动按 **0 算**（视为"没发生"），不让整段崩。

- **分母类列绝不能缺**（实收金额 / 销售额 / 报价金额 / 粉丝数 …），缺了就是真算不了。
- 已标可选列的指标举例：`综合成本率`(税费可选)、`单均净利润`(平台抽成/成本可选)、`销售净利率`(成本/平台扣点/推广费可选)、`内容投产比`(制作成本/投放成本可选)、`复购加权中标率`(复购数可选) ……

```python
import da, pandas as pd
df = pd.read_csv("data/sample_skills.csv").drop(columns=["税费"])   # 故意删掉"税费"

da.技能外包.综合成本率(df)      # ✅ 税费按 0 算，照常出数，不崩
da.能力探测(df, "技能外包")     # ✅ 列表里会标 ⚠️ 可选列 ['税费'] 缺失 → 按0算

# 但若删掉必填列（如实收金额），综合成本率就真算不了（不在可算列表）
```

## 十一、业务看板（一键多图组合）

接单时最常用的几张图，固化成一条命令直接套；也能临时拼任意组合（满足"以后有类似的也能加上"）。

```python
import da, pandas as pd
df = pd.read_csv("data/sample_region_sales.csv")

# 固化看板：首版 6 个覆盖四域
da.图表.看板(df, 名称="地区销售")     # 柱状(地区×销售额) + 饼(占比) + 折线(月份趋势)
da.图表.看板(df, 名称="渠道对比")     # 各渠道 实收金额 的柱 + 饼
da.图表.看板(df, 名称="收益趋势")     # 净到手率折线 + 实收金额柱
da.图表.看板(df, 名称="品类销售")     # 地区×品类 堆叠柱 + 品类 Top10 柱
da.图表.看板(df, 名称="账号表现")     # 粉丝/互动率 折线 + 内容类型 饼
da.图表.看板(df, 名称="接单效率")     # 渠道中标率柱 + 首标时效折线
da.图表.看板清单()                    # 列出所有固化看板及其所需列

# 自定义看板：不写函数，临时拼任意组合
da.图表.自定义看板(df, 图表=[
    ("柱状图", "地区", "销售额"),
    ("饼图",   "地区", "销售额"),
    ("折线图", "月份", "销售额"),
])

# 全局设一次默认风格，之后省略 engine / 预设
da.图表.设定(默认引擎="plotly", 默认预设="商务蓝")
da.图表.看板(df, 名称="地区销售")     # 直接出商务蓝
```

要点：
- **返回形态**：默认返回 `dict`（Jupyter 里多张图依次渲染，最稳）；`组合=True` 时 plotly / pyecharts 拼成单张看板图，seaborn 自动退回逐张（已知限制）。
- **缺列自动跳过**：数据里没有某子图需要的列，看板会跳过该子图并提示，不让整块崩。
- 看某个看板的拼装源码：`da.图表.查看配方(da.图表.地区销售看板)`。

## 十二、库更新便利性（方便后续加字段/指标/看板）

### 1. 装饰器即注册（基础，已就绪）
加指标 = 在某域 `.py` 写一个带 `@metric` 的函数；加看板 = 在 `boards.py` 写一个带 `@看板模板` 的函数。
**不用手动维护任何清单**——装饰器自动收集、自动进 `能力探测` / `看板清单` / 可看配方。
配合可编辑安装 `pip install -e .`：改了源码，Jupyter 里重新 `import da` 立即生效，无需重装、无需重启。

### 2. 脚手架：不想记模板？命令直接吐代码
```python
# 生成一段带 @metric 的完整函数源码（含可选列），粘到 da/<域>/_自定义.py 即可
da.脚手架.生成指标代码(
    "技能外包", "私单净收率",
    ["实收金额", "平台抽成", "税费"],
    "私单净收率 = (实收金额 − 平台抽成 − 税费) / 实收金额",
    可选列=["税费"],
)
# 看板同理：da.脚手架.生成看板代码(名称, 图表列表, 列=...)
```

### 3. 命令自更新：一行命令写文件 + 热加载（连粘都不用粘）
```python
# 给库永久追加一个指标，写文件 + 热加载，立即生效，无需重启 kernel
da.更新.加指标(
    "技能外包", "私单净收率",
    ["实收金额", "平台抽成", "税费"],
    "私单净收率 = (实收金额 − 平台抽成 − 税费) / 实收金额",
    可选列=["税费"],
    计算体='return 安全除法(d["实收金额"].sum() - d["平台抽成"].sum() - d["税费"].sum(), d["实收金额"].sum())',
)
da.技能外包.私单净收率(df)        # 写完即可用

# 给库追加一个看板模板
da.更新.加看板(
    "我的看板",
    [{"标题": "各地区销售额", "类型": "柱状图", "x": "地区", "y": "销售额", "kw": {}},
     {"标题": "各月趋势",   "类型": "折线图", "x": "月份", "y": "销售额", "kw": {}}],
    列=["地区", "销售额", "月份"], 说明="自定义看板",
)
da.图表.看板(df, 名称="我的看板")
```
写入位置（库启动时已自动导入，所以重载后立即可用）：
- 指标 → `da/<域>/_自定义.py`
- 看板 → `da/charts/_自定义看板.py`
